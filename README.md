## 测试IP怎么测才准？别只盯着ping

ping只是第一步，而且是最容易误导人的那一步——去程和回程经常不对称，ping看着不错、回程绕路的情况并不少见。完整的流程是这样：

1. **先ping**：看平均延迟和丢包率，换几个时段测，白天和深夜的结果都可能失真
2. **看回程**：用traceroute或nexttrace对准国内目标IP，比如219.141.147.210（北京电信）、202.96.209.133（上海电信），看回程走的是163骨干（202.97网段）、CN2（59.43网段）、AS9929还是CMI
3. **晚高峰复测**：晚8点到11点再跑一遍ping和mtr，丢包只有这时候才看得出来
4. **拉测速文件**：实测带宽能不能跑满，之前有测评在成都电信环境把50M端口拉满
